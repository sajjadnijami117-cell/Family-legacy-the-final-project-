# কাসেম ও আয়েশা ঐতিহ্য আর্কাইভ (Family Legacy Archive)

*আমাদের শেকড় • আমাদের অহংকার*

বাংলা ভাষার পারিবারিক সংগ্রহশালা। পরিবারের সদস্য, বংশলতিকা, ছবি ও ঘটনার সময়ক্রম এক জায়গায় সংরক্ষণ করা যায়। React + TypeScript + Vite, Tailwind CSS ও shadcn/ui দিয়ে তৈরি।

## সাইটে যা আছে
- **হোম ড্যাশবোর্ড:** সদস্য, মাইলস্টোন ও স্মৃতিচিত্রের সংখ্যা এবং "পারিবারিক সোনালী ইতিহাস"।
- **পারিবারিক গাছ:** দাদা-দাদী থেকে পরবর্তী প্রজন্ম পর্যন্ত বংশলতিকা।
- **সদস্য তালিকা:** প্রতিটি সদস্যের প্রোফাইল, খোঁজার সুবিধাসহ।
- **গ্যালারি** ও **টাইমলাইন:** ছবি যোগ করা এবং ঘটনা লিপিবদ্ধ করা।
- **অ্যাডমিন প্যানেল:** সদস্য, ঘটনা, ছবি ও সহকারী অ্যাডমিন পরিচালনা এবং নতুন সদস্যের অনুরোধ অনুমোদন।
- হালকা/গাঢ় থিম।

## চালানোর নিয়ম
Node.js 20 বা তার বেশি লাগবে।

```bash
npm install
npm run dev       # ডেভেলপমেন্ট সার্ভার
npm run build     # প্রোডাকশন বিল্ড (dist/)
```

`main` ব্রাঞ্চে পুশ করলে GitHub Actions নিজে বিল্ড করে GitHub Pages-এ প্রকাশ করে (Settings → Pages → Source: GitHub Actions)।

## লগইন
- **সদস্য:** নাম বেছে **পারিবারিক কোড** দিয়ে ঢুকতে হয়। কোডটি Supabase-এ একটি শেয়ার্ড অ্যাকাউন্টের পাসওয়ার্ড; সঠিক কোড ছাড়া সার্ভার কোনো তথ্যই দেয় না।
- **অ্যাডমিন:** ইমেইল ও পাসওয়ার্ড (Supabase Auth)। সুপার অ্যাডমিন সহকারী অ্যাডমিন যোগ/বাদ দিতে পারেন।

## ব্যাকএন্ড (Supabase)
- ডেটা (সদস্য, ঘটনা, গ্যালারি, অনুরোধ, লগ) Supabase Postgres-এ থাকে, তাই সব ডিভাইসে একই তথ্য দেখা যায়।
- ছবি Supabase Storage-এর `photos` বাকেটে যায় (পাবলিক লিংক)।
- নিরাপত্তা সার্ভারে ঠিক হয় Row Level Security দিয়ে: পরিবার শুধু পড়তে পারে; সহকারী ইভেন্ট, গ্যালারি ও অনুরোধ বদলাতে পারে; সদস্য যোগ/মোছা ও অ্যাডমিন ব্যবস্থাপনা শুধু সুপার অ্যাডমিন।
- `src/lib/supabase.js`-এর URL ও publishable key পাবলিক হওয়ার জন্যই বানানো; এটা গোপন চাবি নয়। কোনো পাসওয়ার্ড বা secret key এই রিপোতে নেই।

## জানা সীমাবদ্ধতা
- ছবির লিংক পাবলিক; লিংক জানলে যে কেউ ছবি দেখতে পারে।
- পারিবারিক কোড সবাই একই, তাই কেউ কোড শেয়ার করলে ঢোকা যায়। কোড বদলাতে Supabase-এ `family-access` ব্যবহারকারীর পাসওয়ার্ড বদলান।
- বেশিরভাগ সদস্যের ছবি এখনো একই প্লেসহোল্ডার।
